# Obsidian Vault

This project is configured as an Obsidian vault with:
- Daily notes in `daily-notes/` (template: `Templates/daily-note.md`)
- Templates in `Templates/`
- Assets in `assets/`
- Core plugins: file-explorer, search, graph, backlinks, tags, outline, templates, daily-notes, zettelkasten

Open this folder in Obsidian to start.
