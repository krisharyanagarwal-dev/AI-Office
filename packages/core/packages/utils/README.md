# @univerjs/utils

[![npm version](https://img.shields.io/npm/v/@univerjs/utils?style=flat-square)](https://npmjs.com/package/@univerjs/utils)
[![license](https://img.shields.io/npm/l/@univerjs/utils?style=flat-square)](https://npmjs.com/package/@univerjs/utils)
[![downloads](https://img.shields.io/npm/dm/@univerjs/utils?style=flat-square)](https://npmjs.com/package/@univerjs/utils)

`@univerjs/utils` provides utility functions and helpers for the Univer ecosystem. This package includes shared logic for data processing, format conversion, and other common operations used across Univer packages.

## Package Overview

| Feature | Description |
|---------|-------------|
| Data utilities | Functions for parsing, validating, and transforming data formats |
| Format helpers | Utilities for working with different document formats and structures |
| DOM manipulation | Helper functions for DOM operations in the Univer workbench |
| Configuration | Helper functions for managing configuration objects |

## Installation

```sh
pnpm add @univerjs/utils
# or
npm install @univerjs/utils
```

## Usage

```ts
import { someUtilityFunction } from '@univerjs/utils';

// Example usage
const result = someUtilityFunction(input);
```
