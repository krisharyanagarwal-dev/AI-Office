# Assistant Department — General Claude Capabilities

Function: All general AI assistant capabilities — coding, writing, analysis, strategy, planning, research support.

## Capabilities

| Capability | Description |
|---|---|
| Coding | Code generation, review, refactoring, debugging, self-upgrade |
| Writing | Memos, reports, press releases, research papers, documentation |
| Analysis | Financial, statistical, quantitative, market, data |
| Strategy | Trade strategy, company strategy, product strategy, decision frameworks |
| Planning | Project plans, sprint plans, roadmaps, OKRs |
| Research Support | Literature review, data sourcing, fact-checking, synthesis |

## Interface

The assistant department is accessed through the unified company dispatcher. Any task that is not trading-specific (Tier C) or research-specific routes here.

## Autonomy

Tier A — Autonomous. Runs 24/7 without approval for research, writing, coding, analysis.
