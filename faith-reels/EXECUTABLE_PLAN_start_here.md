## The decision this plan makes

**One account first. Not ten.** Prove it, then replicate the system.

The 10-account-at-once idea has zero support in real data. Every account that actually earns was one operator, one niche, daily posting, 6–18 months before money. Ten accounts is a discovery *system for later*, not a starting move.

## The 90-day start

### Phase 1 — Days 1-14: Foundation
- [ ] Create ONE Instagram account (Business/Creator, linked Facebook Page)
- [ ] Name/bio: "Daily Gita verses + one teaching" (or chosen faith) — clear niche, not "all religions"
- [ ] Build 3 reusable motion-graphics templates (verse card, teaching card, carousel)
- [ ] Source 30 verses with written citations — accuracy-checked
- [ ] Write 30 scripts: 3-sec hook + 40-55 words + share trigger ("Share with someone who needs this")
- [ ] Set up link-in-bio → waitlist for the ₹299 product (collect emails before product exists)

### Phase 2 — Days 15-90: Build audience, earn nothing
- [ ] Post 1 Reel daily (same format TheStoic used to reach 500K)
- [ ] Cross-post every Reel to YouTube Shorts + TikTok (Reels drive discovery)
- [ ] Weekly: track aggregated reach, followers, profile clicks (no per-user data)
- [ ] Engage replies daily — faceless accounts with 5%+ engagement command premium rates
- [ ] At 1,000 followers: add affiliate links (faith books/apps) in bio alongside waitlist

### Phase 3 — After day 90 / at milestones
- [ ] At 1k–5k: affiliate + collect emails
- [ ] At 5k–10k: launch the ₹299 product, add Patreon/"support this work"
- [ ] At 10k+: inbound brand deals from faith/wellness brands

### Phase 4 — Expand (only after account 1 works)
- [ ] Copy the proven system to account 2 (different faith), staggered posting, separate device/IP
- [ ] Then 3, then 4 — toward the 10-account network, but only with a proven template
